# Reflection

Reflecting on the Web Foundations and System Design curriculum, the most challenging concept for me was mastering asynchronous JavaScript and API data fetching (`async/await` and handling HTTP responses). Initially, coordinating promises and understanding non-blocking execution felt abstract. I overcame this by building practical mini-projects, stepping through requests in browser DevTools Network tabs, and visualizing the client-server request-response lifecycle repeatedly until it became second nature.

Based on the feedback received on my capstone project, I would improve the error handling and input validation robustness on the front end. Specifically, adding clearer user-facing toast notifications for failed API requests and enhancing responsive mobile layouts would polish the user experience.

Moving forward, my next learning goals are diving deeper into backend development with Node.js and Express to turn API designs into working servers, mastering relational databases and SQL query optimization with PostgreSQL, and learning React to build dynamic, component-driven user interfaces.
